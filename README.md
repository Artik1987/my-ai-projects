# 🤖 Мои AI-проекты

Коллекция моих первых проектов по Python и AI.
Каждый проект — отдельный шаг в обучении.

## 📁 Проекты

### 1. Калькулятор (`hello.py`)
Простой калькулятор в терминале. Спрашивает два числа и выводит сумму, произведение, разность, деление.

**Что использовал:** `input`, `print`, `int`, f-строки, арифметика.

---

### 2. Игра «Угадай число» (`guess.py`)
Компьютер загадывает число от 1 до 100, игрок угадывает. Бот подсказывает «больше/меньше» и хвалит за результат.

**Что использовал:** `while`, `if/elif/else`, `import random`, `break`.

---

### 3. AI-чат в терминале (`ai_chat.py`)
Диалог с искусственным интеллектом через OpenRouter API. Бот помнит контекст разговора.

**Что использовал:** `openai`, `.env`, `while`, список `messages`, `json`.

---

### 4. Telegram AI-бот (`tg_bot.py`)
Полноценный AI-бот в Telegram с памятью. Отвечает на вопросы, помнит пользователя, поддерживает команды `/start`, `/help`, `/clear`.

**Что использовал:** `aiogram`, `asyncio`, `openai`, декораторы, обработка ошибок.

**Бот:** [@artem_ai_helper_bot](https://t.me/artem_ai_helper_bot)

---

### 5. RAG-бот по документам (`tg_rag_bot.py`) ⭐
Telegram-бот, который отвечает на вопросы **по загруженному документу** (база знаний интернет-магазина «Техномир»). Использует архитектуру **RAG** (Retrieval-Augmented Generation) — находит релевантные куски документа и отвечает **только по ним**, не выдумывает.

**Что умеет:**
- Отвечает на вопросы о доставке, оплате, гарантии, возврате
- Цитирует информацию из документа
- Честно говорит «нет информации», если ответа в базе нет
- Fallback на несколько моделей при ошибках API

**Что использовал:** `aiogram`, `scikit-learn` (TF-IDF), `cosine similarity`, chunking, RAG-паттерн, fallback-стратегию.

**Пример работы:**
> **Вопрос:** Сколько стоит доставка в Москве?
> **Ответ:** Доставка в Москве стоит 300 рублей. При заказе от 3000 рублей доставка бесплатна. Также есть вариант экспресс-доставки за 800 рублей.
>
> **Вопрос:** Какой у вас iPhone 15?
> **Ответ:** В базе знаний нет этой информации.
